# Panduan Sumbangan

### 1. Cari atau buka isu
* Semak senarai isu untuk elak konflik
* Buka isu jika temui (*bug*) atau feature

### 2. Fork & Clone
* Klik butang **fork**
* Simpan dalam komputer anda dengan `git clone git@github.com:$USER/devops-bootcamp.git`
ubah $USER dengan username github anda

### 3. Buat branch baru
* Cipta branch `git checkout -b ciri-baru`

### 4. Commit perubahan
* Tulis mesej commit : `git commit -m "Selesai isu #NO: Baiki pepijat XX"`

### 5. Hantar Pull Request (PR)
* Push kod anda: `git push origin ciri-baru`
* Buka halaman GitHub ini dan klik **Compare & pull request**.
* Terangkan perubahan anda secara ringkas dalam deskripsi PR.

Tingkah laku yang sopan dan profesional amat diutamakan. Terima kasih atas sumbangan anda!
